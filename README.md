# Lucky Draw · Arki Technologies × Lantronix

- `index.html` – presenter screen (QR code → registrants → draw). Share this link with the Lantronix team.
- `admin.html` – admin dashboard (passcode protected). Keep this link internal.
- `config.js` – paste the Google Apps Script web app link here.

Data lives in the Google Form responses spreadsheet. The script (Code.gs) adds the tabs
"LD Settings", "LD Winners" and "LD Added". Every winner is written to "LD Winners" the moment it's drawn.
